\# MusicReplacer — 音乐替换器

为 Ballance 的每个关卡播放独立的背景音乐，支持淡入淡出、循环检测和进度显示。



\- 为 13 个关卡分别配置独立音乐

\- 平滑淡入淡出切换

\- 循环播放时提前淡出重播

\- 屏幕进度显示（可配置位置和字体）

\- 音量控制



编译额外依赖

\- \[TagLib](https://taglib.org/) 静态库（x86）



可配置项

| 键名 | 说明 | 默认值 |

|------|------|--------|

| `Folder` | 音乐文件夹路径 | `Music` |

| `Volume` | 主音量 (1-100) | `80` |

| `FadeInStep` | 淡入速度 (0=关闭) | `15` |

| `FadeOutStep` | 淡出速度 (0=关闭) | `20` |

| `LoopFadeLead` | 循环预触发时间 (ms) | `2000` |

| `ShowProgress` | 是否显示进度 | `true` |

| `ProgressX` | 进度 X 位置 (0-1) | `0.5` |

| `ProgressY` | 进度 Y 位置 (0-1) | `0.9` |

| `FontSize` | 字体大小 | `14` |



文件命名

将音乐文件放入游戏根目录下的 Music 文件夹，命名为：

Level\_01.mp3  \~  Level\_13.mp3
